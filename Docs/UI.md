# Интерфейс: стиль Telemetry

Стиль выбран 11.11.2026 из трёх вариантов на холсте https://claude.ai/artifact/8L4txGuYwq911h7DggMDL7
(страница «C · Telemetry»): тёмное стекло, тонкие линии, моноширинные цифры, один лаймовый акцент
(`#C6F432`) и янтарный для наград (`#FFB547`). Тексты в игре — по-английски.

## Где что лежит
| Путь | Что |
|---|---|
| `Assets/_UI/Telemetry/Fonts` | Chakra Petch SemiBold/Bold, IBM Plex Mono Medium/Bold (OFL, лицензии рядом). Кириллицы в Chakra Petch нет |
| `Assets/_UI/Telemetry/Sprites` | Стекло, кнопки, тач-кнопки, иконки, медали, затемнения, логотип, картинка трассы. Рисуются скриптом `Tools/make-telemetry-sprites.py` (2x, 200 px на единицу) |
| `Assets/_UI/Telemetry/Scripts` | Работает в игре: `Tele.cs` (палитра, форматы, режим экрана), `TeleCanvas`, `TeleLayout`, экраны `GarageView`, `TracksView`, `SettingsView`, `HudView`, `ResultsView`, `PauseView`, тач `TeleTouch`, переключатель `TeleSegment`, громкость эффектов `SfxVolume` |
| `Assets/_UI/Telemetry/Editor` | `TeleBuilder` (собирает UI в сценах), `TeleKit` (кирпичики: тексты, кнопки, слайдеры) |

Один MonoBehaviour — один файл с тем же именем: иначе Unity теряет ссылку на скрипт в сцене («Missing script»).

## Как устроено
- **Логика шаблона не переписана.** `CarSelect`, `LevelSelect`, `SettingsMenu`, `Race_Manager`, `Start_Finish_UI`,
  `Pause_Menu`, `InputSystem`, `Nitro`, `Start_Counter`, `FPSCounter` остались на своих объектах; эти объекты стали корнями
  экранов, а их поля UI указывают на новые элементы. В шаблонных скриптах поменялись только форматы строк
  (`1 400`, `P2/5`, `1/2`) и добавлены `Race_Manager.PlayerName/RacerCount`.
- **Настройки.** Старые Dropdown/Slider/Toggle лежат выключенными в `Settings_Menu/Legacy` — это состояние, которое читает
  `SettingsMenu`; `SettingsView` выставляет их и вызывает те же методы.
- **Три раскладки.** `TeleCanvas` держит короткую сторону канваса 720 единиц на ПК и 534 на таче (на телефоне всё крупнее) и
  вписывает `T_Safe` в безопасную зону. `TeleLayout` на элементе хранит положение для `pc`, `land` (телефон горизонтально),
  `port` (вертикально; на ПК в узком окне тоже), может прятать элемент (`touchOnly`, `keysOnly`) и менять размер шрифта/масштаб.
  Подсказки клавиш видны только с клавиатурой в альбомной ориентации.
- **Тач** определяется так же, как в `InputSystem`: WebGL в мобильном браузере, Android/iOS — да, ПК — нет.
- **Камера гаража в портрете** поднимается сдвигом проекции (`PortraitFit`, `GarageLift`), чтобы машина стояла над меню.
  Остальное, что `PortraitFit` делал с канвасами шаблона, к Telemetry-канвасам не применяется.
- **Фоны и Linear color space.** Проект в Linear: тёмная подложка с альфой 0.96 пропускает заметно больше, чем кажется
  (≈ 20 % яркости). Полноэкранные страницы (настройки) — непрозрачные, затемнения трасс/паузы — 0.82–0.985.

## Громкость эффектов (Effects)
`SfxVolume` (ставится сам) масштабирует все AudioSource, кроме музыки (`Load_Settings.music`): в WebGL нет AudioMixer.
Скрипты машины ведут громкость от текущего значения (мотор: `Lerp(volume, …)`), поэтому уменьшенное значение держится только
от LateUpdate до конца кадра (там его и берёт звук), а в конце кадра источнику возвращается его собственное. Ключ
`SfxVolume` в PlayerPrefs, синхронизируется облачным сохранением.

## Как пересобрать UI
Меню **MicroCar → UI → Build Telemetry UI (open scene)** — в открытой сцене Garage или Village; повторный запуск безопасен
(всё созданное пересоздаётся, джойстик шаблона переносится). Пакетно: `-executeMethod MicroCar.UI.EditorTools.TeleBuilder.BuildAll`.
Спрайты: `python Tools/make-telemetry-sprites.py`.

## Проверка в редакторе
- **MicroCar → UI → Simulate Touch (editor)** — телефонная раскладка и тач-управление (`InputSystem` читает это на старте
  сцены, поэтому переключать до Play).
- Окно Game: 1280×720 (ПК), 1688×780 (телефон горизонтально), 780×1688 (вертикально).
- Play меняет общие материалы фар (`Light.mat`, `Light_2.mat`) — не коммитить.
